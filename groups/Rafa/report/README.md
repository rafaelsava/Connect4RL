# Reporte Rafa

El archivo `reporte_rafa.tex` esta pensado para el PDF individual pedido en `Teoria/reto.pdf`.

Requisitos del reto cubiertos:

- Maximo 2 paginas; recomendado 1 a 1.5 paginas.
- Idea principal del agente y enlace/ruta al codigo final.
- Versiones internas del agente: `RafaBase`, `RafaQ`, `RafaImproved`.
- Analisis local sin comparar contra agentes de otros estudiantes.
- Evidencia contra `Random`, self-play y variables de configuracion.
- Propuestas de mejora basadas en evidencia.

Para compilar:

```powershell
cd groups\Rafa\report
pdflatex reporte_rafa.tex
```

Si no tienes LaTeX instalado localmente, sube esta carpeta a Overleaf y compila `reporte_rafa.tex`.
